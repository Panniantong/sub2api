# 账号 Cookie Host 降级时长

账号列表的 Cookie Host 列增加“已降级 X 分钟”，按 `cookie_binding.degraded_since` 每秒更新，悬停显示开始时间。恢复后不显示；后续再次降级单独计时。

轮换任务在账号锁内记录 `extra.codex_cookie_degraded_since`，首次进入现有降级条件时保存，连续重试不重置。成功绑定有效 Host 时与绑定数据一起清除时间；未绑定账号出现可用候选、不再属于降级状态时在下次轮换检查清除。读取 Cookie 库失败时不清除已有时间，写入失败不发布未保存的时间。此字段仅用于显示，不改变降级组、调度条件或代理行为。

历史账号若仍保留过期绑定，从明确的绑定到期时间计算；无绑定且没有历史开始时间的账号，从升级后首次轮换确认降级时记录，之前显示“降级开始时间未记录”，不按页面打开时间伪造历史时长。计时元数据保存在数据库，页面刷新和服务重启不会清零。
