# 动态代理与地区筛选

机场订阅和动态代理可同时存在于托管 Mihomo。地区筛选默认保留原配置，不会因导入动态代理自动放宽。

动态代理的新连接可能立即换 IP，即使节点地址和 SID 相同，也不能把历史地区检测当作当前连接的证明。动态节点因此不使用保存的地区结果，也不参与批量地区检测；面板显示“动态出口 · 地区随连接变化”。这适用于动态代理输入生成的节点，机场订阅中实际也会变化的出口仍需运营者自行识别。

当启用地区筛选时：

- 默认把动态节点当作未知地区，遵循“允许未知地区”设置。
- 可以单独开启“动态代理地区由供应商控制”，保存后动态节点可参与轮换，机场节点继续使用原地区规则。
- 开启供应商控制后，Sub2API 不保证动态出口符合服务器的国家排除/允许列表。需要在供应商侧限定出口地区；`region-Random` 无法保证排除 CN/HK。
- 手动停用、失败和用后移出状态仍然生效，不会被供应商控制选项重置。

“检测地区后立即打票”不能严格解决按连接换 IP 的情况，两次连接可能拿到不同出口。需要严格地区保障时，应使用供应商地区约束或稳定出口。

当前动态模块轮换已导入的代理条目，不会自动生成新 SID，也不保证不同 SID 一定对应不同公网 IP。导入成功、节点被选中、连接成功及取得有效票分别需要验证。
